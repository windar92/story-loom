# 情節織機 · 視覺化劇情節點編輯器（v2）

用「選擇 + 拖拉節點」把小說情節一階段一階段視覺化建構出來。
AI 負責在每個劇情階段生成走向選項、以及實際小說內文;你負責選擇、編輯、調整量尺與方向。

## 功能

- **節點畫布**:可平移/縮放,節點自由拖曳,連成分支劇情樹。
- **節點層級(樹狀視覺)**:主幹 / 粗枝 / 細枝 / 枝葉…可自訂任意層數與顏色;節點依層級顯示不同大小與顏色,一眼看出劇情主軸與細節。子節點自動降一層。
- **量尺系統**:內建奇幻度、尺度、節奏。
  - 每個量尺可設**範圍與步進**(例如「尺度」預設 −20~20、步進 0.5)。
  - 每個量尺可填**上下兩極端的文字定義**(例:暴力程度 低端「徒手捏死小魚」↔ 高端「徒手掐死熟人」),AI 會依定義理解你要的尺度落點。
  - 全域套用,個別節點可覆蓋。
- **選項強化**:生成後的每個選項都能
  - ✏️ **編輯**內容
  - 🔗 **多選合併**成一個
  - 💾 **存入素材庫**重複使用
  - ♻️ **依此方向再生一輪**(以某選項的形式/方向,產同走向的變體)
  - 拖到畫布或按「採用」長出子節點
  - 每次生成的選項數量可在「設定」調整
- **雙模型池**:Groq 與 Gemini,右上角下拉隨時切換。
- **API 用量監測**:右上角顯示今日用量;點開可看本分鐘/本日次數、token、視窗重置時間;Groq 走本站代理時還能讀到伺服器實際剩餘額度。
- **匯出**:組合小說內文(.txt)、整棵樹匯出 **Markdown**(層級對應標題階層)、專案 JSON 備份/還原。
- **儲存**:自動存在瀏覽器 localStorage。

## 一、取得 API 金鑰(免費)

- **Gemini**:https://aistudio.google.com/apikey (`AIza...`)
- **Groq**:https://console.groq.com/keys (`gsk_...`)

金鑰只存在你打開網頁的那台瀏覽器(localStorage),**不會寫進程式碼、不上傳、不進 GitHub**。
repo 公開、Vercel 網址被別人看到也沒關係——別人得填自己的金鑰,用不到你的額度。

## 二、部署到 Vercel(GitHub 連動)

專案結構(很單純):

```
index.html      ← 整個工具
api/groq.js     ← Groq 轉發代理(可選,但建議;解 CORS、能讀剩餘額度)
README.md
```

1. 建 GitHub repo,把上面三個檔(含 `api/` 資料夾)push 上去。
   ```bash
   git init
   git add .
   git commit -m "init 情節織機 v2"
   git branch -M main
   git remote add origin https://github.com/<你的帳號>/<repo>.git
   git push -u origin main
   ```
2. 到 https://vercel.com 用 GitHub 登入 →「Add New… → Project」→ 選這個 repo。
3. Framework Preset 保持 **Other**,其它留空,直接 **Deploy**。Vercel 會自動把 `api/groq.js` 變成一個 Serverless Function,不必額外設定。
4. 打開 `https://<專案名>.vercel.app`,到「設定」貼上金鑰即可。
5. Groq 連線方式建議用預設「自動」——部署後會自動走 `/api/groq` 代理,直連被 CORS 擋的問題就沒了。

之後 `git push` 就會自動重新部署。

> **關於 Groq 代理**:`api/groq.js` 只是把你瀏覽器送來的請求原封不動轉發給 Groq,金鑰仍由前端每次帶上,**不存在伺服器、不記錄**。它的作用是「同源轉發」以繞開瀏覽器直連的 CORS 限制,並順便把 Groq 的剩餘額度標頭帶回給前端顯示。

## 三、使用流程

1. 「作品」填標題、類型、前提、文風。
2. 「量尺」調整或新增量尺(可填兩極端定義);「層級」自訂樹狀階層與顏色。
3. 右上「＋ 節點」開一個主幹節點,填劇情摘要。
4. 選節點 →「✨ 生成後續選項」→ 對選項可編輯 / 合併 / 存素材庫 / 依方向再生;滿意就拖到畫布或按「採用」。
5. 展開情節樹(同一節點可多次生成、採用不同選項形成分支)。
6. 對節點「📝 生成內文」寫出段落。
7. 設某節點為「內文終點」→「📖 內文」串成小說,或「⬇ MD」把整棵樹匯出 Markdown。

## 常見問題

- **Groq 報 CORS / 網路錯誤**:部署後用「自動/代理」即可;若還在本機開檔且要用 Groq,設定改「直連」或先用 Gemini。
- **Gemini 說內容被擋(blockReason)**:把「尺度」調低,或改用 Groq(審查較寬鬆)。
- **模型名稱報錯**:模型會換代。到「設定」改成當下可用的名稱(Gemini:`gemini-2.0-flash`、`gemini-2.5-flash`;Groq:`llama-3.3-70b-versatile` 等)。
- **用量監測數字**:是「本機估算」——只計你在這個瀏覽器透過本工具送出的呼叫;用別的程式打同一把金鑰不會被算到。Groq 走代理時的「伺服器回報」才是帳號實際剩餘量。
- **換裝置資料不見**:資料存瀏覽器本機;換裝置前先「匯出」JSON,新裝置「匯入」。
- **EPUB**:電子書格式(`.epub`),手機/電子書閱讀器可開、自動分章。目前先提供 Markdown 匯出;需要 EPUB 再加。
