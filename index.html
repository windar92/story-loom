操作說明

1. 「設定」貼上 API key。
2. 選節點 → 右側「生成後續選項」。
3. 選項可編輯 / 合併 / 存素材庫 / 依此方向再生一輪。
4. 把選項拖到畫布或按「採用」長出下一個節點。
5. 節點分層級(主幹/粗枝/細枝…),用顏色與大小區分樹狀結構。
6. 拖節點下方紫點到另一節點可手動連線。
全域量尺套用到所有生成。每個量尺可設範圍/步進與兩極端的文字定義,AI 會依定義理解你要的尺度落點。個別節點可在右側覆蓋。
由上到下代表樹狀階層:第 1 層是主幹(劇情主軸),往下是粗枝、細枝…可自訂任意層數與顏色。節點指定層級後會用對應顏色與大小顯示。匯出 Markdown 時層級對應標題階層。
存起來的劇情選項。可插入為選定節點的子節點,或刪除。
金鑰只存在你這台瀏覽器（localStorage），不會上傳、不進程式碼或 GitHub。
